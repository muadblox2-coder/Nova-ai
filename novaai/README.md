# Nova AI

Persönlicher KI-Desktop-Assistent für Windows 11 (PySide6, OpenAI).

- Beim ersten Start wird der OpenAI-API-Schlüssel abgefragt und in den Windows-Anmeldeinformationen gespeichert (keine Adminrechte nötig).
- Kleines Chatfenster oben rechts, immer im Vordergrund, verschiebbar, eigenes ✕ zum Schließen.
- „Bildschirm ansehen“ oder eine Nachricht mit „Löse das“: Vor JEDEM Screenshot erscheint eine Ja/Nein-Abfrage. Ohne „Ja“ wird nichts aufgenommen.
- Nova AI steuert oder schließt keine anderen Programme.

Hinweis: Die EXE ist nicht code-signiert, Windows SmartScreen kann beim ersten Start warnen („Weitere Informationen“ → „Trotzdem ausführen“).
